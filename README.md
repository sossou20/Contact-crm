# Contact-crm
📝 Description du projet  **Contact CRM** est une application web de gestion de la relation client (CRM) développée avec **Angular**[cite: 1]. Elle permet à l'utilisateur de : - Créer, modifier et supprimer des contacts[cite: 1]. - Organiser les contacts par catégories . L'application fonctionne entièrement dans le navigateur
